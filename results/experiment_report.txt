Target and leakage checks
Target: PM2.5_next_hour from PM2.5 exactly one hour later at the same station.
Target alignment was recomputed against the combined source and verified.
Datetime and target columns are excluded from model input features.
Input features: PM2.5, PM10, SO2, NO2, CO, O3, TEMP, PRES, DEWP, RAIN, WSPM, station
Numeric features use median imputation; station uses most-frequent imputation and one-hot encoding.
Each imputer/encoder is inside the model pipeline and is fitted on training data only.

Model configurations
- Linear Regression: LinearRegression(fit_intercept=True); median-impute and standardize numeric features.
- Random Forest Regressor: 100 trees, max_depth=16, min_samples_leaf=5, random_state=42, n_jobs=-1.
- Gradient Boosting Regressor: 100 estimators, learning_rate=0.05, max_depth=3, random_state=42.
- Persistence Baseline: Predict next-hour PM2.5 as current-hour PM2.5.

Important limitations
- The evaluation uses a single chronological holdout from this Beijing dataset; it is not external validation.
- The model predicts one hour ahead using measurements available at the current hour. It does not forecast future weather or pollutant inputs.
- Persistence metrics omit test rows where current PM2.5 is missing so every model is compared on the same examples.
- Missing numeric feature values are imputed with training-set medians; this can underrepresent unusual conditions.
- Internal timestamp gaps are reported, and pairs crossing a gap are excluded; missing data before the first or after the last recorded hour cannot be detected.
- Feature importance is model-specific and does not establish causal relationships.
